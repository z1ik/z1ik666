01 / PROCESS MODE

四种处理模式

从一条龙增强到单独处理，按素材与成片目标选择。默认推荐「全管线」，适合制作抖音高帧率成片。

默认推荐MODE 01

全管线

光效 + 超分 + 补帧一条龙跑完，直接面向高帧率成片。

MODE 02

仅超分

只提升分辨率与画质，修复清晰度，不改变帧率。

MODE 03

仅补帧

只提升帧率，不改变原始分辨率。

MODE 04

仅光效

适合清晰度已经足够，只想加强氛围与质感的素材。

02 / CORE FEATURES

从清晰度到流畅度

软件会根据显卡、内存与 CPU 自动选择性能档位，并在资源不足时主动降级重试，尽量把片子稳定出完。

02× SUPER RESOLUTION

固定 2 倍超分

分辨率提升至 2 倍，同时修复清晰度，让画面更锐利、更干净。

02× / 04× / 06× FPS

真高帧率补帧

30 帧素材可补到 60 / 120 / 180 帧。低配机器自动限制最高 4x，降低跑崩风险。

TY SUPER FRAME

TY超帧画质增强

Real-CUGAN 高画质模型 + 精细编码，老动画与低清片源更锐利干净；速度约慢一半。参数可微调并自动记忆。

TY LIGHT EFFECTS

光效与地面反射

自然倒影、全局光晕与氛围光。默认保持源片色彩，也可调节深浅并先用「可视化」预览。
